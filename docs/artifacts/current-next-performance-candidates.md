## Honest-scope reminders

- `readdirplus-deferred-attrs` is an attr-work reduction slice, not a blanket `readdirplus` speedup claim across directory sizes.
- `readdirplus-page-scan-path-join` is rejected evidence only: some focused 20k counters/tails improved, but the implementation was reverted after 5k `readdir_basic` regressed badly and 20k `readdirplus_basic` p50 still regressed.
- `read-write-small-io-guard-reuse` is a fallback-policy claim bundle; its fast row and the `source_root_path.count` comparison against `current-read-write-surface-smoke.json` are context/non-regression only.
- mutation invalidation currently has observability and focused correctness coverage, not a kept speedup artifact; the previous ordered-range scan bundle is rejected/stale for the current workload scope until a fresh focused subtree baseline exists.
- `open_confined` currently has metadata/open-path attribution context plus rejected `open-confined-frequency` slice evidence, not a kept independent claim-grade bundle; focused `metadata_opendir` improvements and counter reductions do not override failing `open-confined-surface` rows.
- matcher-heavy policy evidence is currently metadata-heavy smoke; descendant/directory proof is still weak.
