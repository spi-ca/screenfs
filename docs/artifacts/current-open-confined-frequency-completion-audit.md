## Completion conclusion

The `open_confined` frequency row is documented to a verifiable stopping point for the current goal:

- the post-review docs converge on `open_confined` as the next measure-first row over mutation invalidation;
- checked-in fallback smoke baselines exist for both mixed `open-confined-surface` and focused `metadata_opendir`;
- the experiment that tried to improve the row is preserved only as rejected evidence;
- focused fallback `opendir` improvement did **not** rescue the failing fallback/fast surface rows;
- current validation is recorded in [`current-open-confined-frequency-validation.log`](current-open-confined-frequency-validation.log);
- no `open_confined` experiment-specific stat-skip/access rewrite code is kept as current implementation; and
- the kept read/write fallback claim remains separate.

Do not read this audit as a kept `open_confined` speedup claim. It is a completion audit for the current evidence state only.
